# Luen Pro

Django sajt + portal aplikacija.

## Lokalno pokretanje

```powershell
cd d:\projects\luenprov2
.\.venv\Scripts\Activate
python manage.py runserver
```

- Sajt: http://127.0.0.1:8000/
- Projekti: http://127.0.0.1:8000/projekti/
- Portal: http://127.0.0.1:8000/prijava/

## Deaktivacija venv

```powershell
deactivate
```
